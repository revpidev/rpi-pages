与源码仓库 changes/ 目录记录相同内容;更新横幅链接到本页(https://revpi.dev/changelog)。

0.1.1(2026-08-16)

三大主线:对齐上游 Pi v0.84.1(T17–T32,parity freeze)、三个常用 Pi 插件的 Rust 移植落地(TE01–TE11)、扩展分发与安装链路打通。

扩展分发与安装(新)

  • rpi install <name>[@<range>]:registry 渠道——裸名解析 revpi.dev 索引,semver 选版(精确 / ^ / ~,缺省最新),安装前预检 rpiAbi 与 minHostVersion;下载 GitHub 直连优先、官网边缘代理回退,sha256 以官网索引记录校验,不匹配立即中止不换源。
  • rpi install github:<owner>/<repo>[@<tag>]:直指 GitHub Release artifact(未收录/私有插件),校验退化为 Release 自带 sidecar 并明示完整性级别差异。
  • .rpix 打包格式:gzip tar,含 rpi-extension.json + 载体 + SHA256SUMS;逐文件校验、原子替换到 ~/.rpi/agent/extensions/<name>/(或 -l 项目级)。
  • 信任提示:install/update 展示 author 与 capabilities 全表;L0 原生插件(无沙箱、全 OS 权限)显著警告,需确认或 --yes。
  • remove / list / update 全链路支持;RPI_REGISTRY_URL 可注入镜像/测试地址,off 整体禁用。
  • 第一方插件随主版本发布:CI 将三个官方插件各自打成 .rpix(Windows x64 / macOS arm64 / Linux x64 与 arm64 glibc;musl 主机无法加载原生扩展,不出插件包),与本体同一 Release 发布、版本锁步,官网索引自动收录并标「官方插件」。
  • revpi.dev 新增 /api/extensions/ 索引 API、/extensions/download/ 下载代理(白名单 + 边缘回源)与插件目录页。

第一方插件移植(TE01–TE11)

  • rpi-ext-mcp-adapter(pi-mcp-adapter v2.24.0):MCP 客户端——配置三源合并、stdio/SSE/HTTP 三传输、OAuth 全流程、代理与 direct 工具、懒连接与会话恢复、状态行与结果折叠渲染;parity 对拍证据链。
  • rpi-ext-subagents(pi-subagents v0.48.0):subagent 工具——六内置 agents 与四级发现、fresh/fork、组合编排与后台异步、worktree 隔离、acceptance gates、supervisor 通道、流式进度与 TUI 可视化、/run /subagents /subagents-doctor;对拍全 MATCH。
  • rpi-ext-smart-fetch(agent-smart-fetch v0.3.17):web_fetch 全管线——batch 并发、meta refresh / alternate 回退、流式下载、进度事件流与组件树渲染。
  • 扩展 ABI 补齐(ADR-0015):unregisterTool / toolUpdate 双载体,完全 additive,RPI_ABI_VERSION 保持 1。

上游对齐 Pi v0.84.1(T17–T32)

  • rpi-ai:v0.84 消息类型与请求选项、流终止语义、provider 修复与 compat 扩展、models refresh 事务化与 OAuth、auth 命令族、新 provider 与模型目录。
  • 主路径:JSON/RPC delta 线格式与 stdout 背压、会话行为簇、资源加载与包管理。
  • rpi-agent:agent 循环微行为与 compaction 契约。
  • rpi-tui:渲染器 trait 化重构、行为修正簇(即时渲染 / grapheme / OSC8 / 键位 / Windows)、LaTeX 与 Mermaid、布局引擎、全屏渲染(alt screen / mouse / kitty)、UI 模式接线与 parity freeze。
  • 扩展 API 面同步上游 12 项(ADR-0013)。

行为变更

  • 移除 npm/pnpm/yarn/bun 自更新分支(ADR-0011 修订):二进制为唯一发行渠道,update --self 恒走真自更新;npm: 扩展包安装不受影响。
  • CI 构建改为仅 tag 触发,分支推送不再自动构建。

修复

  • 主屏渲染器超宽行 panic 杀死运行中会话、满宽行宽度分歧换行漂移花屏——超宽行改截断继续渲染(诊断快照照写 rpi-crash.log 并注明渲染已继续);emoji 字体回退按 2 列渲染的风险字符(✓ 类)计入悲观宽度,满宽风险行保守截断消除行漂移(ADR-0020 / D-086)。
  • 多 native 插件共载失败(abi_stable 按类型 memoize 根因,改 per-path 加载)。
  • SSE 行上限对齐 10MiB(8KiB 上限误吞大行响应)。
  • 全屏热切换输入失效、/settings 两处卡死。
  • file_processor 测试命名竞态;bash 结果截断警告行按终端宽度换行。

官网(revpi.dev)

  • Release 镜像改 Function 边缘代理回源(零存储),404/502 no-store;安装脚本托管站点根。
  • 首页三平台安装面板;docs 快速开始重构;移动端导航与布局修复;favicon。
